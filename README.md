# nuwit-project
To run:
- Flask: move into backend folder, run "python app.py"
- Streamlit: move into frontend folder, run "streamlit run app.py"
First Iteration: Website that allows user to upload images of clothing to create a closet. Then, they may use the website's functionalities to dress their avatar and experiement with outfits!

Second Iteration: Expand the website to allow other uses to join the user, so multiple users can plan cute group outfits. 

Tech Stack: Streamlit for frontend, flask for backend
